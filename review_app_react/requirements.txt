# Databricks Apps deployment manifest — the platform pip-installs THIS file
# (the requirements.txt at the app root, next to app.yaml) when the review
# app is deployed with `databricks apps deploy`. Local dev installs the same
# deps via the [ui] and [local] extras in the repo-root pyproject.toml
# instead (pip install -e ".[ui,local]"); keep the two lists in sync by hand.
#
# WHY THE PIPELINE DEPS ARE HERE. The client-demo tab runs a live 01->04
# pipeline by spawning notebooks/0N_*.py as SUBPROCESSES in this same
# container. Those subprocesses import anthropic / python-docx / openpyxl /
# pypdf, and — because `dbutils` is not a global in a plain Python
# subprocess, so IS_DATABRICKS is False there — they take the LOCAL storage
# path, which needs deltalake. A dep that exists only in pyproject.toml is
# missing at runtime and the failure surfaces in the deployed app, not
# locally. This list was short by exactly those five before 2026-08-21.
#
# frdsttm itself needs no entry: notebooks/ and backend/sharepoint_routes.py
# bootstrap src/ onto sys.path.
#
# The SharePoint/Graph transport (frdsttm.sharepoint) deliberately adds
# NOTHING here — it is standard library only.
